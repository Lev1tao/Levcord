# Levcord

Cliente de escritorio ligero para Discord, nativo (Rust + Slint, sin navegador). Pensado para usar poca RAM y CPU.

## Descargar

Bajá `levcord-windows-x64.exe` desde [Releases](https://github.com/Lev1tao/Levcord/releases/latest) y ejecutalo. Para actualizar, usá el botón con la flecha hacia abajo en la columna de servidores: busca la última versión de este repositorio solo cuando lo tocás.

## Aviso

Los clientes de terceros van en contra de los términos de servicio de Discord. Usalo bajo tu responsabilidad; se recomienda una cuenta secundaria.
